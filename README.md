# מנהל מערכות ימות המשיח

ממשק עברי לניהול מערכות ימות המשיח דרך ה-Management API ושרת MCP.

## פריסה ב-Vercel
1. ייבאו את המאגר הזה ל-Vercel.
2. הוסיפו את משתני הסביבה:
   - `PLAN_SECRET` — מפתח אקראי חזק באורך 32 תווים לפחות, עבור אישור פעולות שינוי.
   - `OAUTH_SECRET` — מפתח אקראי נפרד וחזק באורך 32 תווים לפחות, לחתימה והצפנת אסימוני OAuth.
   - `UPSTASH_REDIS_REST_URL` — כתובת REST של מסד Upstash Redis.
   - `UPSTASH_REDIS_REST_TOKEN` — אסימון REST של אותו מסד Upstash.
   - `PUBLIC_BASE_URL` — כתובת האתר הקבועה, למשל `https://yemot-chatgpt-manager1.vercel.app`.
3. בצעו Deploy מחדש לאחר הוספת כל המשתנים.

## OAuth ל-ChatGPT
השרת מספק OAuth 2.1 Authorization Code עם PKCE (S256), Dynamic Client Registration, גילוי Protected Resource ו-Authorization Server, אסימוני גישה חתומים ומוצפנים, רענון אסימונים וצריכת קוד חד-פעמית דרך Upstash Redis.

כתובת MCP: `https://yemot-chatgpt-manager1.vercel.app/api/mcp`

## אבטחה
- פרטי ההתחברות נשלחים ישירות משרת OAuth ל-Login של ימות המשיח; הם אינם נכתבים ללוגים או נשמרים כטקסט גלוי.
- טוקן ימות המשיח נשמר בתוך אסימון OAuth מוצפן ומוגן בחתימה.
- קודי הרשאה ואסימוני רענון ניתנים לשימוש פעם אחת בלבד באמצעות Upstash Redis.
- אסימוני גישה תקפים לשעה.
- פעולות שינוי עדיין אינן חשופות דרך MCP; הגרסה הנוכחית לקריאה בלבד.
- כל פעולת שינוי בממשק הניהול דורשת תוכנית חתומה שפגה אחרי 5 דקות; מחיקה דורשת אישור נוסף מדויק.

## היקף הגרסה
כלי MCP לקריאת פרטי מערכת, רשימת שלוחות, סטטיסטיקת שלוחה, קריאת קובצי טקסט ובדיקת קבצים. יש להשלים ולבדוק מול תיעוד ימות את סכמות הפרמטרים המדויקות של פעולות יצירה/עדכון לפני הפעלת שינויים.

תיעוד API: https://apiforum.yemot.tel/topic/97/אפשרויות-api-של-חברת-ימות-המשיח
