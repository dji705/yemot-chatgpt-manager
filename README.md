# מנהל מערכות ימות המשיח

ממשק עברי ראשוני לניהול מערכות ימות המשיח דרך ה-Management API הרשמי.

## פריסה ב-Vercel
1. פתחו ב-Vercel את New Project וייבאו את המאגר הזה.
2. הוסיפו Environment Variable בשם `PLAN_SECRET` עם ערך אקראי וחזק (לפחות 32 תווים).
3. בצעו Deploy.

## אבטחה
- פרטי התחברות מוזנים בדפדפן ונשמרים ב-session של הדפדפן בלבד.
- השרת אינו שומר סיסמאות או טוקנים ואינו מדפיס אותם ללוגים.
- כל פעולת שינוי דורשת תוכנית חתומה שפגה אחרי 5 דקות.
- מחיקה דורשת אישור נוסף מדויק.
- יש להפעיל תחילה על מערכת בדיקה.

## היקף הגרסה הראשונה
הגרסה כוללת התחברות, פרטי מערכת, קריאת שלוחות וקבצי טקסט, ותשתית מאובטחת ראשונית לאישור פעולות שינוי. יש להשלים ולבדוק מול תיעוד ימות את סכמות הפרמטרים המדויקות של פעולות יצירת/עדכון שלוחות לפני שימוש מעשי.
